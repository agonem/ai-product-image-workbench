## 运行与复现

沿用锁定依赖，无新增依赖或版本变更。Vue 3.5.43、TypeScript 5.9.3、Vite 7.3.6、Playwright 1.63.0 与 Node 24 的兼容证据为实际类型检查、生产构建和 Chromium 验证；Java 21 / Spring Boot 3.5.16 沿用 T04-PROD。账号初始化与生产配置继续按 17。

以下 Bash 命令从根目录运行；Windows 由 `common.environment()` 保留 JDK 临时目录处理并剔除宿主 `SERVER__*`。不对正在运行的默认 JAR 执行 package/repackage：

```bash
python - <<'PY'
import sys, subprocess
sys.path.insert(0, 'scripts')
from common import ROOT, environment, maven
subprocess.run([*maven(), '-Dworkbench.final-name=business-service-t06-prod', 'spotless:apply', 'verify'], cwd=ROOT/'business-service', env=environment(), check=True)
PY
export BUSINESS_TEST_JAR='business-service/target/business-service-t06-prod.jar'
python scripts/check_db.py --t06-prod-only
python scripts/check_db.py --t06-only
# 选择本机未占用且相互不同的端口；占用会报错，不杀已有进程。
SMOKE_BUSINESS_PORT=28080 SMOKE_IMAGE_PORT=28001 SMOKE_FRONTEND_PORT=25173 python scripts/smoke.py
```

`--t06-prod-only` 创建一次性 PostgreSQL/schema、临时账号、独立 Java 端口、一天有效测试证书，以及独立 `frontend-dist` 生产构建，再以随机端口运行 Vite preview 和 Chromium。浏览器访问 **仅环回 HTTP 测试页面 → Node 代理 → Java HTTPS**；Python 使用仅信任该证书的 SSL context，Node 通过本轮子进程 `NODE_EXTRA_CA_CERTS` 信任证书，产品代理未配置 `secure:false`，没有关闭浏览器 TLS 校验。此证据不代表公网 HTTPS 页面或受信生产证书部署完成。Vite preview 仅供验证，不用作生产服务器。

生产环境以标准 HTTPS 静态服务发布 `frontend/dist`，同源 `/api` 代理使用有效受信的 Java 证书。默认生产构建为 `production-local`；`npm run dev` 默认 `development-only`。可显式设置构建期 `VITE_AUTH_MODE`，错误值拒绝工作，API 模式不匹配不回退。禁止在任何 `VITE_*` 值中放密钥。令牌只存在页面内存；五秒检查撤销、按服务端 expires_at 到期，401 清除页面私有状态。
