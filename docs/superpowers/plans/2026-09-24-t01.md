# T01 仓库骨架 Implementation Plan

> **For agentic workers:** 遵循本项目规则：子代理仅探索与核验，主代理在当前会话逐项实现，不停留在计划交接。

**Goal:** 交付三个可运行最小服务、环境示例、版本锁定、基础检查和 CI。

**Architecture:** 浏览器通过 `/api` 访问 Java；Python 仅提供内部健康端点。默认监听回环地址，不引入数据库、队列、图像算法、认证或 AI 供应商。

**Tech Stack:** Node 24 / Vue 3.5 / Vite 7 / TypeScript 5.9；Java 21 / Spring Boot 3.5 / Maven Wrapper；Python 3.13 / FastAPI / uv / Ruff / pytest。

任务 T01，需求 PRD-G06，验收 ACC-T01，约束 PRD-G01/G03/G04。

目标用户是开发与验收人员，场景为安装、启动、检查连通性与执行自动检查。业务三入口、生成、登录、数据库及生产部署不在本次范围。

| --- | --- | --- |
