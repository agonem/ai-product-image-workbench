# 交互线框与母婴视觉方向 v0.1

此为文字线框与 UI 约束，尚未做视觉稿；具体品牌标识、正式色板、字体授权和设计组件由设计确认。三个独立入口同等突出。

## 首页（桌面）

```text
左栏：品牌 / 工作台 / 素材库 / 任务记录 / 模板管理（管理员）
顶栏：页面标题「商品图工作台」             搜索任务 / 帮助 / 账号
内容：欢迎区「选择今天要制作的图片」
      [赠品主图：商品 + 赠品 + 可选文字] [场景主图：换背景] [卖点主图：人工卖点]
      最近任务列表：类型 / 商品缩略图 / 状态 / 创建时间 / 操作
```

## 编辑页通用骨架

| 区域 | 内容 |
| --- | --- |
| 左栏 | 上传商品、预览与抠图状态；该入口专有参数与模板 |
| 中央 | 可缩放的画布和安全区域；原商品图层有“锁定”提示 |
| 右栏 | 图层列表、生成/预览结果、错误与重试、历史版本 |
| 底栏 | 返回、保存配置、生成预览、下载（成功后） |

赠品页：赠品上传、默认右下的定位控件、拖拽/缩放及可选营销文字。场景页：预设场景卡片、自定义描述、可选风格描述、生成背景与商品合成预览。卖点页：每条人工卖点独立行、预览对应结果、超长提示、版式选择。不同入口不要以步骤向导互相连接。

## 状态和易用性

上传中、需复核抠图、排队、生成中、失败（原因和重试）、完成均有明确反馈；禁用按钮需说明原因。键盘可操作表单；画布编辑需同步数字位置/尺寸输入以方便精调。长文案不能被图片裁切而无提示。移动端先保证查任务、放大预览、下载；全功能拖拽待 D-10。

建议设计 token（仅用于原型）：背景 `#FAF8F4`、卡片 `#FFFFFF`、主文字 `#303A34`、辅助绿 `#9EB8A6`、暖杏 `#EABFA5`；确保按钮及文字对比度实测达标。商品预览画面留足空间，避免装饰与真实商品争夺视觉焦点。母婴素材应以真实授权商品图为准，不用生成模型代画商品作营销成品。

# 2026-10-10 画布（ADR-20261010-S，覆盖上文生成页“右栏上 3/4 画布、下 1/4 结果条”和对话生图两栏布局）

- 生成页（赠品 / 场景 / 卖点）：右栏整块是可平移缩放的画布，点状底纹随拖动移动。画布左边是编辑区（原构图预览 / 生成结果，比例同所选尺寸），右边是“本次结果”（标题“本次结果 N · 全部作品”，结果按 1–2 张一行、3–4 张两列、更多三列排列，保持各自比例）。编辑区工具条浮在画布顶部（白底圆角、轻阴影），“应用文字修改”浮在左下，缩放条在右下（缩小、比例、放大、显示全部）。标题、按钮、失败标记不随缩放变大变小。
- 对话生图：三栏“对话列表 240px | 对话 360–440px | 画布”；≤1280px 时列表在对话上方、画布占右栏；≤900px 依次排列，画布高 min(150vw, 640px)（生成页同；手机上本次结果排在编辑区下方）。画布每条消息一行，行首“第 N 条 + 描述（截断）”；要修改的那张蓝色描边并标“修改这张”；选中的图常显操作按钮。
- 交互：按住拖动平移（从图片上开始拖也算平移，不会打开图片），滚轮以指针为中心缩放（5%–400%），双击图片全屏查看；手机单指拖动、双指缩放；画布有焦点时方向键平移、+/- 缩放、0 显示全部。

# 2026-10-10 补充（ADR-20261010-T，覆盖上一节对话生图的三栏布局）

- 首页：赠品主图、场景主图、卖点主图、对话生图四张功能卡一排（编号 01–04，同样的图标块、两行说明、“立即生成”按钮和角落插图）；≤1100px 两列，≤700px 一列。
- 对话生图：两栏“对话列表 260px | 对话”。对话栏上方是画布（占满剩余高度），下方输入区：一个圆角输入框，左侧 64px 方形素材位（商品图、参考图1、选了才出现的参考图2、“修改这张”卡片），右侧描述文字；输入框下一行为图片名称提示（单行，超出省略）；再下一行为智能体、魔法棒、模型、尺寸、清晰度、数量和“生成”按钮（靠右）。不显示“自动要求”说明。
- 画布：没有消息时中间显示“想生成什么样的图？”、说明和三条示例；之后每行标题“第 N 条 + 描述 + 状态 + 详情”，“详情”对话框列出完整描述、所用图片、模型尺寸状态和看图分析/改写内容。
- 赠品、场景、卖点页：素材位默认空白（虚线框 + 上传图标 + 名称），选择或上传后才显示缩略图。

# 2026-10-10 画布第二期（ADR-20261010-V，对话生图）

- 画布左下角工具条（白底圆角、轻阴影）：“选择 | 抓手”分段按钮、撤销、重做、复制、移除、整理，有移除过的图时多一个“放回已移除（N）”；窄屏只显示图标。右下角仍是缩放条。
- 选择工具下：图片上鼠标为移动手势；选中的图片外有一圈主色描边（不随缩放变粗细）；空白处拖动出现主色细边、浅蓝底的选框。抓手工具或按住空格时鼠标为抓手。
- 每张图上方一行小字说明（不随缩放变大小）：“第 N 条 · 图 M”，副本多一个灰色“副本”小标；每条消息第一张图的说明为“第 N 条 + 描述（截断）+ 状态 + 详情”。
- 图片都被移除时，画布中间提示“这段对话的图片都已从画布移除（仍在“我的作品”里），点左下角“放回已移除”可以放回画布。”
