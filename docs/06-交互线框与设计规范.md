# 交互线框与母婴视觉方向 v0.1

此为文字线框与 UI 约束，尚未做视觉稿；具体品牌标识、正式色板、字体授权和设计组件由设计确认。三个独立入口同等突出。

## 首页（桌面）

```text
左栏：品牌 / 工作台 / 素材库 / 任务记录 / 模板管理（管理员）
顶栏：页面标题「商品图工作台」             搜索任务 / 帮助 / 账号
内容：欢迎区「选择今天要制作的图片」
      [赠品主图：商品 + 赠品 + 可选文字] [场景主图：换背景] [卖点主图：人工卖点]
      最近任务列表：类型 / 商品缩略图 / 状态 / 创建时间 / 操作
```

## 编辑页通用骨架

| 区域 | 内容 |
| --- | --- |
| 左栏 | 上传商品、预览与抠图状态；该入口专有参数与模板 |
| 中央 | 可缩放的画布和安全区域；原商品图层有“锁定”提示 |
| 右栏 | 图层列表、生成/预览结果、错误与重试、历史版本 |
| 底栏 | 返回、保存配置、生成预览、下载（成功后） |

赠品页：赠品上传、默认右下的定位控件、拖拽/缩放及可选营销文字。场景页：预设场景卡片、自定义描述、可选风格描述、生成背景与商品合成预览。卖点页：每条人工卖点独立行、预览对应结果、超长提示、版式选择。不同入口不要以步骤向导互相连接。

## 状态和易用性

上传中、需复核抠图、排队、生成中、失败（原因和重试）、完成均有明确反馈；禁用按钮需说明原因。键盘可操作表单；画布编辑需同步数字位置/尺寸输入以方便精调。长文案不能被图片裁切而无提示。移动端先保证查任务、放大预览、下载；全功能拖拽待 D-10。

建议设计 token（仅用于原型）：背景 `#FAF8F4`、卡片 `#FFFFFF`、主文字 `#303A34`、辅助绿 `#9EB8A6`、暖杏 `#EABFA5`；确保按钮及文字对比度实测达标。商品预览画面留足空间，避免装饰与真实商品争夺视觉焦点。母婴素材应以真实授权商品图为准，不用生成模型代画商品作营销成品。

# 2026-09-30 企业风格重做（ADR-20260929-C，覆盖以上各节）

依据用户确认的原型 v2（企业风格）。本节为当前实现的界面规范。

- 视觉：浅灰底 `#F2F3F5`、白色卡片、单一主色 `#1D5BD8`（浅底 `#E8F0FF`）、圆角 6/8px、控件高 32px、单色线条图标、系统中文字体（不加载外网字体，内网可用）。只做浅色主题。点缀：导航选中左侧色条、卡片悬停轻微上浮、生成中闪光、空状态矢量插图、轻阴影。
- 框架：左侧导航按功能分组（首页 / 图片生成 / 素材与作品 / 设置），底部为头像、账号、角色与退出图标；不显示登录有效期与审核提示文字。提示消息在右上角浮层，确认类 6 秒后自动消失，错误需手动关闭。
- 生成页（三入口同一骨架）：左栏上方素材槽（只有图标与“商品图/赠品图”字样，点击出现“从素材库选择 / 上传图片”，选中后显示缩略图），下方可折叠参数区（一次展开一组，收起时右侧显示当前选择），底部固定“生成图片”按钮（多张时显示“生成 N 张”，不可生成时在按钮上方说明原因）。右栏上约 3/4 为画布：工具条（构图预览/生成结果、文字框、对照原图、缩放、尺寸），生成前只显示“商品/赠品/文字”虚线区域（不做合成预览），生成后显示结果与可拖动、可缩放的文字框，对照原图为左右滑动分隔；有结果时左下角提示“拖动虚线框调整文字位置，改完点右侧按钮，只重排文字、不重新生成。”，右下角“应用文字修改”。下约 1/4 为“最近结果”缩略图条：悬停显示对照/下载/删除，失败显示“失败”与重试。
- 参数：赠品页＝赠品位置（左侧/右侧/左下/右下）、背景（纯色 6 种或描述）、营销文字（标题、标签、位置左上/居中/右上、大小小/中/大、颜色 4 种）、输出设置；场景页＝场景卡片（6 个预设 + 自定义）与补充描述、输出设置；卖点页＝卖点文字（无颜色，标题用第一个风格的颜色）、风格（每种一张）、输出设置。输出设置＝模型（名称 + 接口供应商，默认选中管理员的默认模型）、尺寸、数量（同宽下拉）。输出格式固定 PNG。
- 其他页面：首页（欢迎区、三张功能卡、最近作品）；素材管理（类型切换、上传按钮、图片网格、悬停删除）；我的作品（按功能筛选、悬停对照/下载/删除）；任务记录（表格：功能、时间、次数、张数、状态标签、查看）；账号与安全（我的账号：账号信息、修改密码含确认；管理员另有“账号管理”表格与新建/重置对话框）；模型配置（模型表格：默认标记、走代理与启用开关、设为默认/更换密钥/改名；网络代理卡片）。
- 窄屏（≤900px）：导航折为顶部，页面整体滚动，生成页上下排列，无横向滚动。

# 2026-09-30 New API 风格（ADR-20260930-E，覆盖上一节的框架与配色）

依据用户确认的原型 v3（https://claude.ai/artifact/3raWkSeXnYiMBbx2S37VUY），参考 New API 新版控制台（shadcn/ui 风格）。生成页、参数与画布结构沿用上一节。

- 框架：全宽顶栏（左：收起侧栏按钮、标志与名称；右：模拟模式标记与提示消息）；下方为浅灰底上的左侧栏与内嵌圆角内容卡片（16px 圆角、浅边框）。
- 左侧栏按功能分组，组名为浅灰小字：概览（首页）/ 图片生成（三个入口）/ 素材与作品（素材管理、我的作品、任务记录）/ 个人中心（我的账号）/ 管理员（账号管理、模型配置，仅管理员）。当前项为白底、主色文字与轻阴影。侧栏可收起为图标（只在本次打开期间记住）。用户头像、账号、角色与退出图标保留在左栏底部（用户选择）。
- 视觉：天蓝主色 `#1683D8`、浅底 `#E7F3FC`，底色 `#F4F6F8`，边框 `#E6E9EE`，控件 10px、卡片 14px 圆角，控件高 34px；页面标题 20px 加一行灰色说明；页面级筛选用胶囊式标签（素材类型、作品筛选、模型/网络代理）。
- 放大查看：素材、作品、首页最近作品与结果条的图片可全屏查看（缩放、上一张/下一张、下载、Esc 关闭）。
- 素材选择对话框分“素材库 / 我的作品”；赠品背景增加“保持原图”；账号管理可删除（页面内确认）；模型配置可添加第三方接口（接口地址，http 仅内网并提示明文风险）。

# 2026-09-30 第二阶段（ADR-20260930-F）

- 管理员分组新增：数据看板（排第一）、模板管理、图片管理、操作日志。
- 数据看板：右上 7/14/30 天切换；五个数字卡（生成任务/失败、生成图片、成功率、平均/最长耗时、当前排队/生成中）；每日任务柱状图（失败部分红色叠加）；按功能、按模型、按账号三张表。
- 模板管理：标签“场景预设 / 卖点风格 / 版本记录”。场景每行为缩略示意、名称、给模型的场景描述，可上移、下移、删除；风格每行带标题/标签/点缀颜色与预览。底部固定“修改说明 + 放弃修改 + 保存并发布”。版本记录列出版本号、说明、发布人、时间，可“回退到此版本”或“恢复内置默认”（都需页内确认，都会生成新版本）。
- 图片管理：标签“原图 / 作品”，按账号筛选；卡片显示账号、功能、时间；点图放大查看，悬停出现删除（页内确认，标题写明“删除 某账号 的…”）。
- 操作日志：按操作人、动作筛选，每行显示时间、操作人、动作中文名、对象；“加载更多”分页。
- 生成页：素材区标题右侧“我的模板”（保存当前参数为模板、点名称套用、删除）；画布工具栏依次为撤销、重做（图标按钮，Ctrl+Z / Ctrl+Y，在输入框内不拦截）、文字框、图层（显示文字、锁定文字位置、显示构图区域、显示参考线）、对照原图、缩放、尺寸。参考线为三等分、中线与 5% 安全边；拖动文字框靠近 5%/50%/95% 时吸附并显示洋红对齐线。窄屏时工具栏换行，不产生横向滚动。
