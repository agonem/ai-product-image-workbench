# 验收标准与测试样本 v0.1

**总体完成条件**：业务代表完成真实素材人工验图，确定性规则自动测试通过，权限/故障/重试用例通过，当前规格的来源和批准人记录完毕。性能阈值及比例待确认，不虚构通过率。

| ID | 验收场景 | 预期 |
| --- | --- | --- |
| ACC-01 / G01 | 用含小字 Logo、按钮、透明/反光边缘的白底商品图生成三类图 | 成品商品形状、文字、Logo、颜色和结构可人工确认与源图一致；记录原图哈希、alpha 和变换；生成 API 不接收要求重画商品的原图 |
| ACC-02 / G03 | 从首页分别直达三功能 | 任一功能单独上传到下载，不要求另两功能数据 |
| ACC-03 / S01 | 赠品上传后默认右下，拖到左侧并缩放 | 最终位置与预览一致，不出现角标；非真实比例允许；赠品保持来源可追溯 |
| ACC-04 / S02 | 预设场景和自由场景各生成一次 | 背景无额外商品或乱码（人工审）；原商品层来自上传图；失败可重试且有明确原因 |
| ACC-05 / S03 | 输入两条卖点，含数字/中文/单位 | 输出两张对应候选图；文案不被改写；超长文案提示调整且不静默截断 |
| ACC-06 / G04 | 查看结果页 | 可预览、下载；界面无拼多多发布入口；后台无发布任务 |
| ACC-07 | 相同 Idempotency-Key 连续提交 / 不同 payload 重用 key | 前者返回同一任务；后者明确冲突；不出现双份产物 |
| ACC-08 | Worker 重复回执、宕机、超时和旧 attempt 晚到 | 状态可恢复，旧 attempt 不覆盖新产物，失败可追踪 |
| ACC-09 | 非项目成员猜测 asset/task ID | 读取、下载、重试均被拒绝；短时下载地址不会泄露长期访问权 |
| ACC-10 | 发布场景模板 v2 后查看旧任务 | 旧任务仍显示 v1 配置快照与结果；新任务可选 v2 |
| ACC-11 | 模板/图片文件异常 | 伪造 MIME、超大尺寸、损坏文件、包含异常元数据的输入被拒绝并有可理解的错误 |
| ACC-12 | 不同分辨率与浏览器宽度查看工作台 | 主要信息和操作可见；拖拽支持范围按决策确定 |

**测试素材包必须由业务提供并确认可用于测试**：4–8 张母婴产品白底图（包装细字、白色商品/白背景、透明件、圆角、绒毛、反光和多部件至少各一个案例，可一图多项）；2 张赠品图（透明/非透明）；经批准的人工卖点与两种场景期望；授权和数据保留说明。测试时保存样本哈希、手工审核标记与问题截图；不要将真实受限素材提交公共仓库。

验证层次：图层合成/布局/文字溢出的确定性单元测试；前端↔Java 与 Java↔Python 的 Schema/契约测试；上传→队列→生成→下载的集成测试；边缘、包装细字和背景伪商品的人工审图；失败注入。AI 背景随机输出采用质量抽样与审核，不做脆弱的整图像素快照。

## ACC-T01：开发骨架验收

对应 T01 / PRD-G06，并保持 PRD-G01/G03/G04 的范围边界。

- 三个目录可独立安装、检查、启动；锁文件与版本选择依据可复现。
- 前端通过 Java 健康接口展示加载、连接成功、失败和重试；不直接调用 Python。
- Java 与 Python 健康接口符合 `02` 第 0 节；没有伪造的上传、任务或生成成功接口。
- 格式/静态检查、类型检查、后端测试、前端构建及真实 HTTP 启动冒烟检查均有可运行命令；CI 调用同一批检查。
- 环境示例不含真实密钥；默认只监听本机；缓存、产物、真实环境文件和素材不纳入版本控制。
- 本任务不生成图片，不适用商品边缘/Logo/包装文字人工审图；ACC-01..12 的业务验收仍留待相应任务。
