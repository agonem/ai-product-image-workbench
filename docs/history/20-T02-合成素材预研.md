## 实现前范围及判定

- S1：仅程序绘制合成素材；保留原始 PNG 与 SHA-256，处理不覆盖原文件。
- S2：白底边界连通分割作为可替换启发式实验；从分割候选只取 alpha，合成 RGB 始终来自原始图像。透明/白色/毛绒等真实边缘无质量承诺。不能自动写 APPROVED。
- S3：原图坐标整数裁切（右/下不包含）→单一比例缩放（输出宽高四舍五入，记录实际尺寸）→以中心逆时针旋转并扩展画布→平移合成；记录参数、顺序、alpha/源哈希和库版本。
- S4：主体及赠品分层合成，输出 PNG/JPEG 和原图/alpha/切出/变换/合成对照，记录技术资源预算；无 AI 调用，无平台预设。
- S5：自动测试覆盖 alpha 与 RGB 来源隔离、几何和非法/超预算参数、输入不变与输出格式。所有视觉质量条目标记“待人工确认”；合成测试通过不替代真实样本。

本轮仅离线 Python PoC，不接 Worker/API/数据库，不改 v1 请求/迁移或放开任务成功。T07/T08 仍需真实 T02 关口。
