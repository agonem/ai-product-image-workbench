# T06 三入口工作台、任务与历史

日期：2026-09-26。需求：PRD-G02/G03/G04/G06、PRD-S01/S02/S03；任务：T06。

## 实现范围

面向运营人员，赠品图、场景图、卖点图三个入口平级、独立填写参数，切换入口保留各自输入。前端只访问 Java；本地账号仅用于开发。提供项目选择/创建、PRODUCT/GIFT 上传、受权原图查看、提交、状态轮询、失败重试和数据库历史分页。会话仅保存在内存，退出/401清除私有状态与对象URL。网络提交结果不确定时锁定原请求与幂等键，明确提供同键重发。

Java 新增 dev-local 的配置、项目素材、项目任务列表，只返回必要元数据，沿用 ACTIVE/owner 检查。模板仅列已发布且非禁用版本，配置为空时不伪造默认值。历史的测试夹具标记取自冻结快照。V1/V2 迁移与既有严格 task-response Schema 未修改。

真实抠图审核与三类生成算法不可用；普通上传仍显示边缘待审核并阻止提交。测试成功显示“开发/测试任务完成 · 非真实成品”，预览、下载与历史均明确标记。没有发布/上架功能，不决定 AI 供应商、平台规格或生产认证。

## 运行与复现

先按 README 安装锁定依赖。开发者自己的环境按 [T04指南](../13-T04开发账号与上传.md) 创建私有本地账号、配置一次性或开发数据库、`APP_ENV=development`、`SPRING_PROFILES_ACTIVE=dev-local`、私有对象目录与独立Worker令牌。不得将真实密钥提交仓库。

分别运行 `python scripts/dev.py business`、`python scripts/dev.py frontend`，打开 `http://127.0.0.1:5173`；任务执行另运行 `python scripts/dev.py worker`。默认健康模式没有登录接口。前端继续使用已有 `DEV_API_TARGET` 代理配置，不直接连接Python。

无人工配置的完整自动验收（仓库根目录）：

```text
python scripts/check.py
npm --prefix frontend exec -- playwright install chromium
python scripts/check_db.py --t06-only
```

最后一条需要 PostgreSQL 17 原生工具（`PG_BIN` 或项目已安装的工具路径），创建临时集群/随机账号/独立schema及纯合成素材，启动Java/Vite/普通Worker并调用 `npm run test:page`。检查结束后停止所创建进程；账号摘要、临时DB、日志、截图只保留在忽略的 `.artifacts/`。禁止把该测试夹具作为真实商品生成演示。

CI已有一次性PostgreSQL服务时，设置既有 `DB_TEST_*` 并执行 `python scripts/check_t06.py`。不可把 `DB_TEST_*` 指向真实业务数据库。

## 曾失败及修复

旧构建首先在新增接口认证检查失败；新控制器曾漏注册统一异常处理，已修正401/404行为。前端lint发现子组件直接修改prop，改为显式v-model。测试准备曾触发不可变时间戳/对象键唯一约束，修正夹具而未放宽业务规则。浏览器严格标签定位因select包含option文字未命中，改用可访问角色/名称后通过。独立代码核验发现分页上限和断网轮询恢复边界，均修复并加入检查。
