## ADR-20260930-D：上传不限格式与像素（修复业务账号上传被拒）

状态：通过。决定人：用户。日期：2026-09-30。依据：用户反馈“业务账号上传商品图和赠品图提示‘只支持内容匹配的 PNG/JPEG 图片’”，并要求“上传图片不限制格式，不限制像素大小”。

- 原因（测试服务器访问日志核实）：服务端要求浏览器声明的文件类型与实际内容完全一致，并拒绝带 EXIF、色彩配置、文字等附加信息的 PNG/JPEG；同一张图在不同电脑、不同文件名下声明类型不同，于是时好时坏（日志中 415/422 与 201 交替出现），与账号无关。
- 决定：以文件内容判断类型，不再看浏览器声明；PNG/JPEG 原样保存（保留全部元数据，包括手机照片方向、CMYK、色彩配置）。其他浏览器能打开的格式（WebP、GIF 首帧、BMP、AVIF、ICO 等）由页面转为无损 PNG 后保存——保存的是像素内容相同的 PNG，不是原文件字节（对 AGENTS“原始上传文件保留”的明确例外）。HEIC、TIFF 等浏览器打不开的格式提示先另存为 JPG/PNG。
- 大小：取消业务上的像素限制，只保留防止服务器被拖垮的安全上限——单个文件 50MB、1 亿像素（`OBJECT_MAX_BYTES`、`OBJECT_MAX_PIXELS` 可调，技术上限 64MB / 4 亿像素）；nginx 上传上限 60MB。服务端只读文件头取尺寸，不整图解码；发给模型时 Worker 按 EXIF 方向转正、转 RGB、缩到 1536px。
- 影响：接口 §7 上传规则、验收 ACC-T04 A3、V4-A14、V4-B10。

## ADR-20260930-E：作品当素材、保持原图背景、删除账号、放大查看、第三方接口、New API 风格界面

状态：通过。决定人：用户。日期：2026-09-30。依据：本轮需求清单与三个选择题答复（按 New API 风格原型实施；退出与用户信息保留在左栏底部；删除账号时一并删除其图片）。原型：https://claude.ai/artifact/3raWkSeXnYiMBbx2S37VUY 。

- 作品当素材：素材槽的“从素材库选择”增加“我的作品”；选中后复制一份作为新的商品图或赠品图（记录来源作品），原作品与新素材互不影响；同一作品同一用途重复选择时返回已有副本。
- 保持原图背景：赠品+文字主图的“背景”增加“保持原图”（接口 `background.mode = ORIGINAL`，不带颜色与描述）；提示词要求保持商品图原有背景，只加入赠品。模型仍可能改动背景，结果照常人工审核。
- 删除账号：管理员可删除他人账号（不能删除自己、不能删除最后一个启用管理员、账号有排队或生成中的任务时需稍后再删）。删除后立即退出且不能再登录，账号名可重新创建；该账号的原图、生成结果与模型原图一并删除（先写删除记录，再删文件，不可恢复）；项目、任务与审计行保留作历史。
- 放大查看：素材管理、我的作品、首页最近作品、生成页结果条可放大查看（缩放、上一张/下一张、下载）。
- 第三方接口：恢复 OpenAI 格式、Gemini 格式第三方接口（取代 ADR-20260929-C 的“删除第三方”）；接口地址 https 任意、http 仅限内网 IP；内网地址即使勾选“走代理”也直连。
- 界面：参考 New API 新版控制台（shadcn/ui 风格）：全宽顶栏 + 按功能分组的左侧栏（概览 / 图片生成 / 素材与作品 / 个人中心 / 管理员），内容放在内嵌圆角卡片中，天蓝主色、较大圆角、浅灰边框；侧栏可收起为图标。“我的账号”“账号管理”拆为左栏独立入口。用户信息与退出图标按用户选择保留在左栏底部；不做深色切换（需要浏览器存储保存偏好，而本系统保持浏览器存储为空）。
- 影响：迁移 V11；接口 §18；验收 V4-A15/A16 与页面用例。
