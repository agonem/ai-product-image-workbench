## A：背景与成品分离（PRD-S02 / PRD-G06）

新增 v3 场景契约，保留 v1/v2 契约和历史迁移。`output` 为最终成品的 width、height、aspect_ratio、format、count；尺寸须与比例相符。背景请求只发送经路由能力核验的 aspect_ratio，不发送本地导出尺寸和格式。固定模型、provider，无 fallback。供应商默认生成 PNG/JPEG（其他实际格式明确拒绝）；本地按 cover-center-v1 等比例缩放居中裁切至最终画布，记录输入尺寸、缩放及裁切框。保留供应商原始背景、独立阴影、商品原图与 alpha 哈希。

批次保持 ALL_OR_NOTHING：全部产物成功才可见，部分失败不发布。每次付费调用前通过 Java 租约保护的唯一调用登记（attempt + ordinal）；已登记调用不能再次发送，进程崩溃或结果不确定不会自动重发。旧 v2 保持原来的严格供应商参数语义。

官方依据（2026-09-28）：https://openrouter.ai/docs/guides/overview/multimodal/image-generation 与 https://openrouter.ai/docs/api/api-reference/images/list-image-model-endpoints 。resolution/output_format 为可选项，默认规格由供应商决定；provider_tag 固定路由，supported_parameters 按 endpoint 核验。

## C：管理员接口与模型设置（PRD-G06）

仅生产 ADMIN 管理。Java 加密保存密钥，外部主密钥不入库；响应仅返回密钥是否配置及掩码。配置版本不可变，保存新版本只影响新任务，重试仍使用原版本；替换凭据创建版本，不静默切换运行任务。后台启用默认配置优先于私有环境配置；没有后台默认配置时沿用环境启动方式。Worker 仅能通过有效租约读取对应任务的私有配置。OpenRouter 地址固定官方 HTTPS；其他适配器明确不可用，本轮不宣称通用 URL 协议兼容。
