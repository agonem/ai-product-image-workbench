- 先读：AGENTS.md、本文件、[04 ADR-20260929](04-待决策事项.md)、[02 §16](02-接口与数据契约.md)、[03 ACC-V4](03-验收标准与测试样本.md)。
- 检查命令（仓库根目录，Windows 需 `PG_BIN` 或 `.tools/postgresql-17.11`）：
  - `python scripts/check.py`：前端/Java/Python 全部非数据库检查。
  - 构建独立 JAR：`scripts/common.py` 的 `maven()` 执行 `-Dworkbench.final-name=<名称> clean package -DskipTests`，**必须带 `clean`**（target 残留旧迁移会导致 Flyway 版本冲突）；然后设 `BUSINESS_TEST_JAR=business-service/target/<名称>.jar`。
  - `python scripts/check_db.py --migrations-only | --core-only | --t05-only | --t06-only | --t06-prod-only`。
  - 真实调用只能经用户授权：`scripts/v4_real_calibration.py`（需 `OPENROUTER_ENV_FILE` 指向私有 `.env`、`OPENROUTER_PROVIDER_TAG=openai`）。
- 经验坑：在 bash heredoc 里写带反斜杠的代码会被改坏（改用写文件再执行）；前端 ajv 严格模式要求 `required` 的键在同层 `properties` 声明、`required` 所在子模式带 `type`；所有进入 `contracts/fixtures/cases.json` 的契约必须在 `frontend/src/contracts/validate.ts` 注册；Windows 下 Python 写文件要 `newline="\n"`。
- 边界不变：Java 管业务与数据库，Python 不连数据库；前端只调 Java；密钥不进日志和 Git；新结果一律 PENDING；不自动上架；已发布迁移不修改；每个可验收子任务单独提交，不 amend。
