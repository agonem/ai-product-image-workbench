## 生产启动与首次初始化

沿用锁定的 JDK 21、Spring Boot 3.5.16、PostgreSQL 17、Flyway 与 JDK PBKDF2；未新增依赖。新增 V3，V1/V2 不变。生产使用独立数据库/存储/Worker 凭据，勿复用 dev-local 测试数据。

1. 在私有目录生成首次 ADMIN 摘要（交互读取口令，不将口令放命令参数）：

   `python scripts/prod_accounts.py --file local-data/prod-bootstrap.json --username <管理员用户名>`

   工具拒绝覆盖文件，POSIX 创建为 0600；Windows 必须用系统 ACL 限制到服务账号及受权运维。首次成功启动后移除 `PROD_BOOTSTRAP_FILE` 配置并安全移除引导文件；已有账号时即使文件改变也不会重置账号。数据库为空且无有效引导文件则启动失败。无公开注册或默认口令。

2. 按仓库常规命令构建 Java；为避免占用正在运行的默认 JAR，也可运行 Maven Wrapper：

   `business-service/mvnw.cmd -B -ntp -f business-service/pom.xml -Dworkbench.final-name=business-service-t04-prod verify`

   Git Bash/Linux 可使用 `bash business-service/mvnw` 替代 `.cmd`。Windows 若出现 JDK selector 临时目录问题，使用 `scripts/common.py` 的 `environment()`/`maven()` 启动方式（下文检查命令），不修改全局设置。

3. 启动环境配置模板见 `.env.prod-local.example`。注入独立 DB 配置、私有对象目录、Worker token 和受信 TLS 证书；必须 `SPRING_PROFILES_ACTIVE=prod-local`、`APP_ENV=production`、`SERVER_SSL_ENABLED=true`。Java 不自动读取 `.env` 文件，由运维注入环境。运行 `java -jar business-service/target/business-service-t04-prod.jar`。

4. 使用 HTTPS API `/api/v1/local-auth/login`；生产管理员通过 `/api/v1/admin/accounts` 管理账号。完整输入/响应见 [契约第 9 节](02-接口与数据契约.md)。密码仅通过 HTTPS JSON 发送；不使用 URL、命令行或日志承载秘密。账号管理 ADMIN 不自动获得跨项目图片读取权；未确定的成员共享不开放。现有 Vue 页面仍是开发工作台，不可据此宣称生产页面完成。

会话重启后保留，默认 900 秒固定到期，改密/重置/状态变更撤销目标所有会话。数据库仅保存 token 摘要；每用户最多 20 个有效会话。部署共享登录限速默认每 60 秒 60 次，可在 1–600 内配置，过载返回 429；此为认证防护，不是 D-12 图片业务并发配额。最后 ACTIVE ADMIN 不能被禁用；如所有管理员凭据遗失，需受控运维处理，不存在匿名重置入口。
