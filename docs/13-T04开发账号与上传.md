# T04 可先行：开发账号、项目和素材

需求 PRD-G02/G06、PRD-S01；ACC-T04-DEV、ACC-09/11。D-05 未确认，本版本只提供开发环境适配器。没有正式 SSO、组织/成员/管理员权限决定，没有实现 T06 页面。

## 本地启动

沿用 README 的 Node/Java/Python/uv 环境和 `python scripts/check.py` 构建。PostgreSQL 连接及私有 OBJECT_STORE_ROOT 按 11 配置，V1/V2 迁移保持不变，不需要新迁移。

先在仓库根目录创建新账号文件（已有文件拒绝覆盖）：

```text
python scripts/dev_accounts.py --username alice --username bob
```

命令逐个隐藏输入密码；至少 12、最多 128 字符。默认写入已忽略的 `local-data/dev-accounts.json`，也可用 `--file` 指向仓库之外的私有路径。自动化可加 `--password-stdin`，逐行从标准输入读取；不要将密码写进命令行、Git、日志或文档。文件仅含 username、随机 user_id、独立 salt 与 PBKDF2 摘要。文件不是无敏感信息的公共配置，应限制为服务账号可读；Windows 请配置相应 ACL，POSIX 创建模式为 0600。

将以下变量设置到 Java **进程环境**；`.env.example` 不会被程序自动读取：

| 变量 | 开发用法 |
| --- | --- |
| SPRING_PROFILES_ACTIVE | dev-local（自动包含 runtime/database） |
| APP_ENV | development；其他值拒绝启动 |
| DEV_ACCOUNTS_FILE | 上述账号文件的绝对路径 |
| DEV_SESSION_SECONDS | 可选，默认 900 秒，范围 2..3600 |
| DB_URL / DB_USER / DB_PASSWORD | 自己的开发数据库；密码不写 URL |
| OBJECT_STORE_ROOT | 仅服务账号可写的私有目录 |
| RUNTIME_WORKER_TOKEN | 自行生成的至少 32 字符随机值，仍与用户会话分离 |
| BUSINESS_HOST | 127.0.0.1 或 ::1；其他绑定拒绝启动 |

执行 `python scripts/dev.py business`。dev-local 不使用 RUNTIME_API_TOKEN/RUNTIME_USER_ID；只能搭配 dev-local/runtime/database 三个 profile，不能叠加 production 等 profile。默认健康模式和单独 runtime 模式没有登录端点。T05 原静态 token 模式仍可用于既有测试，不是生产认证。

启动时只为账号文件中的 user_id 创建缺失的开发用户，不覆盖已有用户状态或授予角色。**账号文件只在启动时读取**：换密码、删账号、编辑文件后必须重启；重启清空所有会话。运行时禁用已有账号可由开发数据库维护者将对应 `users.status` 置为 DISABLED，每次登录/会话请求都会检查；再次启动不会自动恢复 ACTIVE。不要用新 user_id 替换旧记录来转移项目归属。

## API 操作

1. `POST /api/v1/auth/login`，JSON `{username,password}`；取得短时 access_token。请求/响应均不得记录到共享日志。
2. 后续请求使用 `Authorization: Bearer <access_token>`，不使用 cookie 或 URL token。`GET /api/v1/auth/me` 检查身份，`POST /api/v1/auth/logout` 撤销当前会话。
3. `POST /api/v1/projects`，JSON `{name}` 创建自己的项目；`GET /api/v1/projects` 返回最近 100 个自己的项目；`GET /api/v1/projects/{id}` 查单个项目。
4. `POST /api/v1/projects/{id}/assets?kind=PRODUCT`（或 GIFT），请求体直接为图片字节，Content-Type 必须为 image/png 或 image/jpeg。返回素材 ID、摘要、尺寸、PENDING 状态及需要同样鉴权的 content_url。
5. `GET /api/v1/assets/{id}` 查元数据；`GET /api/v1/assets/{id}/content` 原始字节代理。没有公开存储目录或永久外链，也没有完成上传、删除、自动审核或 ALPHA 上传入口。

已有 T05 任务接口会从当前请求解析身份，不再固定为进程用户；幂等键仍按用户+功能隔离。上传原图不等于 alpha 审核通过，直接生成仍返回 CUTOUT_REVIEW_REQUIRED。真实 pipeline 和人工审核属于 T02/T07..T09。

## 开发输入限制与恢复

OBJECT_MAX_BYTES 默认 10 MiB、OBJECT_MAX_PIXELS 默认 1600 万，沿用 T05 可配置范围；单边最大 16384 像素。同时只处理 2 个上传解码，忙时 429；这些是技术保护值，不是平台尺寸、业务额度或生产容量承诺。请求支持明确长度和 chunked；中断/不完整内容不创建对象或数据库素材。错误不回显密码、路径、原文件名或图片内容。

PNG 检查结构/CRC/结束位置；允许 IHDR/PLTE/IDAT/IEND/tRNS/sRGB/gAMA/cHRM/pHYs，其他 chunk 拒绝。JPEG 允许常规基线/渐进图像及 JFIF APP0；未支持的 EXIF/ICC/COM/其他 APP 元数据拒绝。完整解码前检查尺寸/像素，解码警告也拒绝。合法但带未支持元数据的照片可能被拒绝，须提供无附加元数据的 PNG/JPEG；服务端不剥离元数据、不旋转、不重编码，不自行认定白底或商品内容。

原始字节写入随机独立 key 并不可覆盖。资产和审计在同一数据库事务登记；事务失败不出现可访问素材，但可能留私有孤立对象。D-08 未决定，因此不做自动删除，沿用 T05 的保留/人工调查方式。不要将整个对象根目录暴露为静态网站。

会话在内存仅存 token 摘要，最多 256 个未过期会话；每进程登录技术限制为 30 次/分钟，含失败尝试。账号文件/进程重启是开发操作机制，不承诺跨实例会话或生产账号生命周期。

## 验证与技术依据

```text
python scripts/check.py
python scripts/check_db.py
python scripts/smoke.py
```

check_db 创建一次性 PostgreSQL，运行 T05 回归及 T04 双账号/上传真实 HTTP 检查并停止自建进程。CI 对一次性 DB_TEST_* 环境执行 `python scripts/check_t04.py`；须先构建 Java jar、安装 Python 锁定依赖和 psql。测试只使用合成 PNG 及 `contracts/fixtures/t04-synthetic-jpeg.base64`（Java ImageIO 生成的 4×3 单色 JPEG，无用户素材），账号/密码每次随机生成，放忽略目录。

未新增第三方依赖；使用 Java 21 内置 [PBKDF2WithHmacSHA256](https://docs.oracle.com/en/java/javase/21/docs/specs/security/standard-names.html) 和 [ImageReader](https://docs.oracle.com/en/java/javase/21/docs/api/java.desktop/javax/imageio/ImageReader.html)。采用 600000 次 PBKDF2-HMAC-SHA256，参考 [OWASP 密码存储指导](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html) 的对应参数；这不等于选定生产认证方案。内容检测、随机服务端文件名、大小限制和私有存储参考 [OWASP 上传指导](https://cheatsheetseries.owasp.org/cheatsheets/File_Upload_Cheat_Sheet.html)。版本与 T05 相同，以本次实际 Java/Python 互通测试验证兼容。
